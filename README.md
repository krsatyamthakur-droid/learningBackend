# learningBackend

A collection of Node.js and backend learning exercises, assignments, HTTP examples, middleware experiments, and frontend integration practice.

## Contents

- Existing backend lessons and projects (`backend 1` through `backend9`)
- Node.js fundamentals and CLI assignment (`class 1`)
- HTTP and HTTPS examples (`class 2  HTTP`)
- HTTP server, middleware, CORS, and frontend examples (`class 3 creating http server`, `class 3 middleware and cors`)
- Authentication practice (`Auth`)
- Frontend examples (`frontend`)

## Running an example

Each exercise that contains a `package.json` can be run independently:

```bash
cd "path/to/exercise"
npm install
node index.js
```

Use the entry point shown in that exercise when it differs from `index.js`.

## Notes

This repository is for learning and experimentation. Keep secrets in local environment files and do not commit credentials.
